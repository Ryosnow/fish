# 周进度（当日 / 本周口径切换）

> **项目文档 · 已定稿设计，待实现**。架构总览见 [ARCHITECTURE.md](../ARCHITECTURE.md)，作息规则见 [作息规则.md](作息规则.md)，菜单栏绘制见 [菜单栏进度环.md](菜单栏进度环.md)。
> 状态：设计已确认（2026-11-13），尚未实现。

## 目标

在现有「当日净工作进度」之外，新增**周进度** = 本周累计净工时 ÷ 每周总工时。

例：每周总工时 45h，周一 15:00 已工作 3h（不含午休）→ 约 6.7%。

菜单栏**圆环 + 百分比数**可在「当日 / 本周」两种口径间切换；**可拖动的悬浮窗保持不变**（仍显示当日进度）。

## 设计原则

- 零硬编码工时：每周总工时默认从作息规则自动算出，不预置 45h 之类的数字。
- 与上一轮「作息规则」的通用配置化一脉相承：自动算出的目标会随星期规则、日期覆盖、调休补班 / 放假自动变化。
- 允许手动覆盖：合同工时固定（如 45h）时，可填一个固定目标压过自动值。
- 悬浮窗刻意不接新口径（用户要求），因此菜单栏周进度与悬浮窗当日进度可能不同，用 tooltip 说明避免困惑。

## 数据模型（`Prefs`，均 `decodeIfPresent`，旧配置零影响）

```swift
var progressMode: Int = 0             // 0 当日 / 1 本周
var weeklyTargetHours: Double? = nil  // nil = 自动从作息规则算；>0 = 手动固定目标
```

`validated()` 校验：`progressMode` 收敛到 0/1；`weeklyTargetHours` 非正或非法值按 nil 处理。

## 纯函数（`Model/Time.swift`）

| 函数 | 说明 |
| --- | --- |
| `weekTargetSeconds(_ now: Date, _ p: Prefs) -> Double` | 手动值 × 3600；否则遍历本周一~周日，对每个 `isWorkday()` 的日子用 `schedule(for:)` 求当天净工时并求和 |
| `weekWorkedSeconds(_ now: Date, _ p: Prefs) -> Double` | 本周一 00:00 至今累计净工时；逐日按当天作息，今天只累计到 `min(now, 下班)` 并扣除已过午休；未来天计 0 |
| `weekProgress(_ now: Date, _ p: Prefs) -> Double` | `clamp(worked / target, 0...1)`；目标为 0 时返回 0 |
| `displayProgress(_ now: Date, _ p: Prefs, _ state: CountdownState) -> Double` | `progressMode == 1 ? weekProgress : state.progress` |

每日净工时口径与现有 `Shift.totalWork` 一致：`(下班 − 上班) − 午休`，跨零点（`end <= start` 视为次日）一视同仁；`dayOverrides`（补班 / 放假）经 `isWorkday()` 生效，周目标同步增减。周起点为**周一**（`Calendar.current`），按本地时区。

## 数据流

```
computeState → st.progress（当日）
                    │
displayProgress(now, prefs, state)   ← 按 progressMode 选口径
        ├── AppDelegate.updateStatusItem → ringView.progress
        │        ├── ringSegments(phase:progress:) 画环
        │        └── menuPercentText(progress:) 画百分比
        └── MenuView 总览 Tab 的进度条 + 百分比（保持一致）
```

**悬浮窗（`PanelRoot`）不接 `displayProgress`**，仍用 `st.progress`，按用户要求不变。

## 环形态（周模式）

现有 `ringSegments` 用当日 `phase` 做形态编码：已下班=满环+中心点、休息日=虚线空环。这些是「当日状态」专属，和周进度会打架（周进度 60% 时画满环没有意义）。

因此**周模式下环改为纯周进度弧**：底环 + 按 `weekProgress` 填充的实色弧，不再画满环中心点 / 虚线空环；当日状态仍由悬浮窗与 tooltip 承载。隐身时沿用现有降级（极淡空心圈、隐藏百分比）。

日模式完全保持现状，不改任何现有绘制逻辑。

## 百分比精度

日模式保持整数 `41%`；周模式显示 **1 位小数**（`6.7%`，否则小进度被整数吃掉）。需验证 `100.0%` 在 58pt 项宽内不越界（13.5pt 常规体），必要时把项宽从 58pt 微调到 64pt，并同步自测的右对齐断言。

## 切换入口

| 入口 | 行为 |
| --- | --- |
| 设置「显示 → 菜单栏」 | 新增 `Picker`「进度口径：当日 / 本周」，写入 `progressMode` |
| 右键菜单 | 新增「切换进度口径」一键在 0/1 间切换（不占用左键，左键仍开面板） |
| 总览 Tab | 进度条上方或「今天下班时间」附近显示当前口径标签（如「本周」），避免和悬浮窗数字不一致时困惑 |

## 边界与兼容

- 旧配置无 `progressMode` / `weeklyTargetHours` → 默认 0（当日）、nil（自动目标），**行为与现在完全一致**。
- 目标为 0（全周休息 / 未配作息 / 无工作日）→ 周进度 0%。
- 周进度 >100% → clamp 到 100%；跨零点班次跨周时按班次归属日累计。
- 调休补班 / 放假同时影响「已工作」与「周目标」两侧，保持比值语义正确。
- 手动目标存在时忽略自动求和，但仍按实际已工作工时 clamp。
