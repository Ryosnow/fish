## 分层与依赖规则

| 规则 | 说明 |
| --- | --- |
| Model 是纯的 | `Model/Prefs.swift` 与 `Model/Time.swift` 只 `import Foundation`，不依赖 UI 框架；时间计算全部是可单测的纯函数 |
| UI 不碰宿主 | SwiftUI 视图只通过 `@EnvironmentObject var store` 读写数据，不直接创建 / 操作 `NSWindow` / `NSStatusItem` |
| AppDelegate 是唯一组装者 | 创建菜单栏项、Popover、悬浮窗、右键菜单，绑定 `$prefs` sink、注册热键、监听通知 |
| MenuBar 只服务菜单栏 | `Ring.swift` 被 `AppDelegate` 独占使用 |
| Tests 只依赖 Model | `SelfTest.swift` 只测纯函数（另外用 `NSFont` 量百分比文字宽度，故额外 `import AppKit`） |

顶层 `private` 声明与使用方同文件：`QUOTES` 与 `workingQuote` / `computeState` 同在 `Model/Time.swift`；3 个热键全局变量与 `registerGlobalHotKey` 同在 `App/HotKey.swift`。拆分时未改动任何访问控制。

## `main.swift` 规则

Swift 规定**顶层可执行语句只能出现在 `main.swift`**，因此该文件只有约 28 行：

| 分支 | 作用 |
| --- | --- |
| `--version-check` | 打印版本与系统版本，验证可执行文件 / 动态库可加载 |
| `--hotkey-check` | 注册一次全局热键，检测是否被占用 |
| `--selftest` | 跑 `runSelfTest()` 的 38 项断言，失败退出非 0 |
| 默认 | `NSApplication.shared` → `AppDelegate` → `.accessory` → `app.run()` |

其他文件只放声明。全局变量由编译器按需惰性初始化，不再有「按源码顺序初始化」的问题（旧单文件时代 `--selftest` 曾因此 segfault）。

## 构建

[build.sh](../build.sh) 四步，产物为 `../下班倒计时.app`：

1. `make_icon.py` 生成 1024px PNG → `sips` 切 10 个尺寸 → `iconutil` 打包 `AppIcon.icns`
2. `find Sources -name '*.swift' | sort` 收集**全部** Swift 文件 → `xcrun swiftc -O -target arm64-apple-macosx13.0` 编译到 `.app/Contents/MacOS/`
3. 复制 `Info.plist` → `plutil -lint` → `codesign --force --sign -`（ad-hoc，identifier `com.rumor.offwork-countdown`）
4. `codesign -v` + 依次跑 3 个 CLI 自检

Swift 以**文件名**识别 `main.swift` 为入口，与其他文件的传入顺序无关。构建产物 `.app` / `.icns` 不入库（`.gitignore` 已忽略）。

## 持久化

`UserDefaults` 单个 key `com.rumor.offwork-countdown.prefs.v1`，值为 `Prefs` 的 JSON。`Prefs.init(from:)` 对每个字段用 `decodeIfPresent`，旧配置缺字段不报错；`palette` / `customHex` 两个字段已废弃，仅保留以兼容旧配置。窗口位置 `panelOrigin` 单独记录并由 `ensurePanelOnScreen()` 校验。
