# 界面与可访问性

> **项目文档 · 描述当前实现**。架构总览见 [ARCHITECTURE.md](../ARCHITECTURE.md)，构建见 [README.md](../README.md)。
> 对应源码：`Sources/UI/*`、`Sources/App/Store.swift`、`Sources/UI/PanelRoot.swift`。

## 设计语言

整体是**黑白灰 + 系统强调色**，参考 Cursor / macOS 系统设置：

- 主色固定 `Color.primary`（浅色近黑 / 深色近白），数字、进度条、百分比、状态圆点全部**单色、无渐变**。界面不再提供配色自定义。
- `PanelColor`（`UI/Theme.swift`）通过 `NSColor` dynamicProvider 提供浅 / 深两套语义色：

| 语义色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `background` | `#FFFFFF` | `#1C1C1E` | 设置面板与悬浮窗底色 |
| `card` | `#F5F5F7` | `#2C2C2E` | 分组卡片、未选中按钮 |
| `secondary` | `#6E6E73` | `#A1A1A6` | 次要文字、副标题 |

- 唯一的彩色来自系统强调色（复选框选中态），由系统控制，自动适配。
- `preferredScheme(theme)` 把 `theme = 0/1/2` 映射为跟随系统 / 深色 / 浅色。

## 设置面板

`NSPopover`（330×440），按**渐进式披露**收敛成 3 个 Tab，避免一屏堆满控件：

| Tab | 内容 |
| --- | --- |
| 总览 | 大号倒计时、进度条 + 百分比、状态说明、快捷键提示 |
| 作息 | 上下班时间、工作日、午休、节假日 / 调休（折叠） |

「上下班时间」按**两行**排列（「上班」一行、「下班」一行，右侧各一个时间选择器，行间 `CardSeparator`）。时间选择器用 `.fixedSize()` 保留内在宽度、标签用 `.lineLimit(1).fixedSize()` 防止被 HStack 压缩成竖排；面板高度 440pt 保证作息 Tab 内容不需滚动。
| 显示 | 悬浮窗 / 菜单栏 / 外观三张 `SettingsCard`；「高级」折叠收纳置顶、提示音、登录自启、收缩、隐身 30 分 |

- **分组卡片**：标题在卡片外（小灰字），卡片白底细边框 + 行间 `CardSeparator` 细线；每 Tab 顶部有大标题。
- **开关**：`CheckRow` 用 macOS 原生 `.toggleStyle(.checkbox)`（蓝色圆角方块 + 标题 + 一行说明），不用蓝色胶囊 `.switch`。
- **底部固定操作栏**：「立即隐身 / 退出」。
- **错误提示**：`Store.timeError` 在 Tab 栏下方渲染统一、可关闭的错误横幅，任何 Tab 都可见（登录自启失败在「显示 → 高级」触发也能看到）。

### 可点击元素

色板（已移除配色自定义后为工作日按钮与迷你视图）、工作日按钮、迷你视图展开全部是 `Button` + `.buttonStyle(.plain)`，不用 `onTapGesture`；带 `accessibilityLabel` / `accessibilityValue` / `.isSelected`，支持键盘 Tab 聚焦与 VoiceOver。工作日按钮选中态用背景色 + 语音值区分，不只靠颜色。

## 悬浮窗

- 与设置面板统一为 `PanelColor.background` 纯白底 + 细边框，不再用 `.ultraThinMaterial`（材质会透出桌面壁纸颜色）。
- 小字全部用语义字体：标题 `.footnote`、说明 / 百分比 `.caption`、语录 `.footnote`、收缩按钮图标 `.caption`；不再写死 9.5 / 10 / 11pt。
- 大号倒计时数字（紧凑 30pt / 完整 42pt）用 `@ScaledMetric(relativeTo:)` 包装，跟随 Dynamic Type；`DigitsText` 保留 `.minimumScaleFactor(0.7)` 兜底。总览 Tab 的大数字与百分比同样接入 `ScaledMetric`。
- 收缩态的 🕕 emoji 换成 `clock` SF Symbol（emoji 只留在状态文案里作品牌趣味）。
- `st.sub` 允许 2 行 + `fixedSize(horizontal: false, vertical: true)`，大字号下换行而不是截断；宽度固定 200 / 300，高度由 `resizePanelToFit()` 用 `NSHostingView.fittingSize` 自适应。

## 登录自启状态同步

`Store.syncLaunchAtLogin()` 保证开关与系统真实状态一致：

- 读 `SMAppService.mainApp.status`，`.enabled` 视为已注册；否则回退检查 `~/Library/LaunchAgents/com.rumor.offwork-countdown.plist` 是否存在。
- 纯函数 `launchAtLoginEnabled(systemRegistered:plistExists:)` 判定：任一为真即视为开。
- **调用时机**：`applicationDidFinishLaunching` 一次，以及每次打开设置面板时（用户可能刚在系统设置里增删过登录项）。
- **只读**：同步不尝试注册 / 注销；plist 不可读按未启用处理。注册失败走 `timeError` 横幅，开关保持旧值。
- 同步改写 `prefs.launchAtLogin` 会触发 `@Published` → `save()` / `applyPrefs`，与启动时已有的 `applyPrefs` 幂等。
