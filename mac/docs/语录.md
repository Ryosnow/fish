# 悬浮窗语录

> **项目文档 · 描述当前实现**。对应源码：`Sources/Model/Time.swift`（`QUOTES` / `pick` / `workingQuote`）、`Sources/UI/PanelRoot.swift`（显示）。

## 是什么

悬浮窗底部那行会随时间轮换的短句（`CountdownState.quote`）。不是滚动动画，而是**每分钟换一条**：`pick(_:_:)` 用 `Int(now.timeIntervalSince1970 / 60) % 数组长度` 取模，所以同一分类内按数组长度循环（现在每类 8–26 条，其中工作时段 6 类各 18–26 条，循环周期约 8–26 分钟，不会几秒就重复）。

## 场景与条数

共 **11 类 182 条 + 5 组星期语气 70 条**（合计 252 条）：

| 分类 | 条数 | 触发时机 |
| --- | --- | --- |
| `rest` | 12 | 休息日 / 没配工作日 |
| `before` | 12 | 上班前 |
| `far` | 26 | 工作中，距下班 ≥ 4 小时 |
| `mid` | 24 | 2–4 小时 |
| `hour` | 22 | 1–2 小时 |
| `minutes` | 20 | 10 分钟–1 小时 |
| `final` | 18 | 最后 10 分钟 |
| `off` | 12 | 刚下班 |
| `late` | 8 | 下班超过 4 小时（深夜） |
| `break` | 10 | 休息段进行中（午饭 / 晚饭…） |
| `night` | 18 | 21:00–06:00 仍在工作 |

## 按星期几的语气（工作日白天）

`WEEKDAY_QUOTES`：周一~周五各 14 条，语气按一周的节奏渐变：

| 星期 | 语气 |
| --- | --- |
| 周一 | 缓启动、轻微自嘲（先把脑子开机） |
| 周二 | 稳、按部就班 |
| 周三 | 过半、偏文艺（一周翻到中间那一页） |
| 周四 | 望向周五、有盼头 |
| 周五 | 轻快、准点收工 |

生效范围：`workingQuote` 在**工作日白天且距下班 ≥ 1 小时**时优先用当天这组，按分钟轮换。以下情况保持原逻辑：21:00–06:00 深夜工作走 `night`（关怀语气不按星期）、周末或无对应星期池走原 `far/mid/hour`、距下班 < 1 小时走 `minutes/final`（收尾语境优先，不被星期语气盖掉）。

风格选的是**偏文艺的轻幽默**，不用毒舌，和其余 182 条不割裂；每条仍一个 emoji，未改动任何现有文案的 emoji。

## 挑选顺序

`workingQuote(remain:now:)`：先判断小时（深夜优先走 `night`）→ 工作日白天且 `remain >= 3600` 走 `WEEKDAY_QUOTES[weekday]` → 否则按剩余时长依次落到 `far / mid / hour / minutes / final`。`computeState` 在休息段中改取 `break`，下班超过 4 小时取 `late`，休息日取 `rest`，上班前取 `before`。所有分支都走 `pick` 轮换，没有写死单句。

## 风格约定（增删时请沿用）

- 中文、一句、约 15–25 字，悬浮窗两行内放得下
- 工作时段主题尽量分散：会议 / 需求 / 代码 / 邮件 / 提交 / 犯困 / 喝水 / 收尾 / 摸鱼，避免连续几条都在说同一件事
- 打工人 / 摸鱼的轻幽默，温和、不油腻、不鸡汤、不催奋进
- 每条末尾 1 个 emoji，不堆砌
- 用「」做引号，避免半角 `"` 破坏 Swift 字符串
- 不写具体时间、星期、人名或公司名（保持通用）

## 如何增删

编辑 `Sources/Model/Time.swift` 的 `QUOTES`，改完跑 `./build.sh`：`--selftest` 会校验「11 类且每类不少于 5 条」「各时段返回非空」「深夜与白天走不同池」「休息中取自 break 池」。分类 key 不要删（`workingQuote` / `computeState` 用 `!` 强解），新增分类需同步改挑选逻辑。
