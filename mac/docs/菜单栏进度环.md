# 菜单栏进度环

> **项目文档 · 描述当前实现**。架构总览见 [ARCHITECTURE.md](../ARCHITECTURE.md)，构建与逐模块要点见 [README.md](../README.md)。
> 对应源码：`Sources/MenuBar/Ring.swift`、`Sources/App/AppDelegate.swift`、`Sources/UI/MenuView.swift`（开关）。

## 概述

`menuStyle = 2` 是默认的菜单栏档位：用 14pt 细圆环表达**今日净工作进度**，不用数字也能看出还剩多久。另外两档是「完整」（带时间文字）与「精简」（到分钟）。

| 档位 | `menuStyle` | 项宽 | 内容 |
| --- | --- | --- | --- |
| 完整 | 0 | 变长 | `🕕 02:32:30` 状态 + 时间 |
| 精简 | 1 | 42pt | `2:32` / `下班` / `休息` |
| **进度环（默认）** | 2 | 58pt（开百分比）/ 20pt（关） | 环 + 右下色点 + 可选百分比 |

形态编码为主、颜色为辅：状态靠形状区分（色弱友好），颜色只用于表达工作进度阶段。描边用 `NSColor.controlTextColor` 自动适配深浅模式。

## 视觉规格

| 项 | 当前值 |
| --- | --- |
| 环直径 | 14pt（半径 7） |
| 线宽 | 2.5pt |
| 圆心 | `x = 10`（纯环 20pt 时居中；带文字时靠左） |
| 填充方向 | 从 12 点方向顺时针 |
| 填充比例 | `st.progress`（今日净工作进度，已扣午休），clamp 到 0–1 |
| 底环 | `controlTextColor` alpha 0.20 |
| 进度弧 | `controlTextColor` alpha 0.95，圆角线帽 |

自绘 `NSView` 而非 SF Symbol，是为了让直径、线宽、视觉重量完全可控（早期多次调 `NSImage.size` 无效的根因就是符号有内在尺寸）。

## 状态形态映射

| 状态 | `phase` | 形态 |
| --- | --- | --- |
| 等下班 | `.working` / `.before`（含午休） | 浅灰底环 + 实色进度弧；午休时弧末端加一个小圆点表示暂停 |
| 已下班 | `.off` | 满环 + 中心小实心点（完成标记） |
| 休息日 | `.rest` | 8 段短弧组成的虚线空环 |
| 隐身 | 任意 | 极淡空心圈（alpha 0.10），不暴露状态 |

## 右下角进度色点

- **几何**：由 `ringDotGeometry(ringCenter:ringRadius:)` 给出，位于环右下角（`dist = r + 1.5`），直径 6pt（半径 3.0），故意压住环右下角一小段；不增加项宽，自测验证在 20×22 视图内不越界。
- **颜色**：`ringDotColor(phase:progress:isStealth:)` 返回 RGB 分量，四段纯色、到边界直接切换，无渐变。

| 进度 | 颜色 | 说明 |
| --- | --- | --- |
| 0–25% | 绿 `#5BAE84` | 低饱和 |
| 25–50% | 黄 `#DFC25E` | 低饱和 |
| 50–75% | 橙 `#E0A355` | 低饱和 |
| 75–100% | 正红 `#FF2D2D` | R=255、G=B=45，不偏橙不偏粉；单独提亮作醒目警示 |

- **显示范围**：仅 `.working` / `.before`；`.off` / `.rest` / 隐身不显示，避免下班后还挂着红点像警告。
- 环本身仍是单色、形态编码不变，色弱用户不受影响。

## 右侧百分比文字

- `menuPercentText(progress:isStealth:)` 返回 `41%` 形式的单色文字；`13.5pt` 系统常规体（`.regular`），`NSColor.controlTextColor` 适配深浅。
- **右对齐**：`x = round(width - 2 - textWidth)`，右边距固定 2pt；`y` 同样取整，避免半像素绘制发虚。`100%` 宽 35pt、`x = 21`，`21 + 35 = 56 ≤ 58`，不越界。
- 位数变化时空白移到环与文字之间，右侧始终只有 2pt，不会像左对齐那样堆出大片空白。
- **项宽**：`menuPercent` 开启时视图与 `statusItem.length` 为 58pt，关闭时为 20pt；`currentPercentShown` 检测变化并重建 item，宽度即时更新。
- **状态**：取 `st.progress` clamp 0–1（休息日 0%、已下班 100%）；隐身时文字返回 `nil` 但项宽不变，避免旁边图标左右跳动。
- 开关在设置「显示 → 菜单栏」，仅进度环档可用，其他档 disabled。

## 架构与数据流

- 三档**统一使用 `NSStatusBarButton`**（系统原生点击 / 高亮 / 菜单）。已废弃的 `statusItem.view` 不再使用。
- `RingStatusView: NSView` 作为 button 的**子视图**，`hitTest` 返回 `nil` 让鼠标事件穿透到 button；它只负责画内容，不接管交互。
- `AppDelegate` 实现 `NSPopoverDelegate`，在 `popoverDidShow/DidClose` 调用 `button.highlight(true/false)`，面板打开期间保持系统高亮。
- `tick()` 每 0.5s 把 `(phase, progress, isStealth)` 写入 view，**仅值变化时** `needsDisplay = true`（进度一分钟才动一点，避免空转）。
- `viewDidChangeEffectiveAppearance()` 触发重绘。
- 绘制参数全部抽成纯函数，便于断言：`ringSegments` / `ringDotColor` / `ringDotGeometry` / `menuPercentText`。

## 边界与降级

- `progress` clamp 0–1；未知 `phase` 只画底环。
- `ringUnavailable`：系统 button 创建失败时把有效档位降到文字档，避免每帧反复重建。
- 文字两档仍用 `CountdownState.menu` / `menuShort`；`currentIconName` 缓存保留给文字档的隐身图标。

## 自测覆盖

`--selftest` 共 38 项，其中与本模块相关的有：进度环 clamp 与三态形态、隐身降级、色点四档绿黄橙正红与边界（0.249 / 0.25 / 0.499 / 0.5 / 0.749 / 0.75）、状态隐藏、几何不越界、正红不偏粉、菜单栏百分比 clamp / 隐身隐藏 / `100%` 不越界。

构建后还会验证：三档切换启动、深浅模式、隐身 / 恢复、左键开面板与右键菜单、菜单栏项与悬浮窗尺寸、popover 定位链路。
