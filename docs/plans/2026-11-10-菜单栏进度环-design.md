# 菜单栏进度环设计

- 日期：2026-11-10
- 状态：**已实现**（2026-11-10）
- 关联项目：下班倒计时 macOS 应用（`其他/OffWorkCountdown/`）

## 目标与约束

解决的问题：菜单栏占用空间偏大、图标与相邻 app 的图标尺寸/风格不一致、三态图标只能表达「还没下班」而看不出还剩多久。

约束：

- 菜单栏**不显示任何数字或文字**
- 项宽 ≤ 20pt（当前 26pt）
- 保持现有交互：悬停 tooltip、左键开面板、右键开菜单、隐身
- 保留「完整 / 精简」两档文字模式，行为不变
- 不联网、不新增依赖、不新增数据源

## 视觉规格

- 14pt 直径细圆环，线宽约 2pt，在 20pt 项宽内居中
- 自绘图形，单色模板色跟随系统深浅模式（`NSColor.controlTextColor`）
- 从 12 点方向顺时针填充，比例 = `st.progress`（今日净工作进度，已含午休扣除），clamp 到 0–1
- 直径、线宽、视觉重量全部可控，不再受 SF Symbol 内在尺寸约束（这是此前多次调 `NSImage.size` 无效的根因）

## 状态映射（只靠形态，不用颜色）

| 状态 | phase | 形态 |
| --- | --- | --- |
| 等下班 | `.working` / `.before`（含午休） | 浅灰底环 + 实色进度弧；午休时弧末端加一个小圆点表示暂停 |
| 已下班 | `.off` | 满环 + 中心小实心点（完成标记） |
| 休息日 | `.rest` | 8 段短弧组成的虚线空环 |
| 隐身 | 任意 | 极淡空心圈，不暴露状态 |

形态编码为主：色弱友好、自动适配深浅模式、视觉更克制。颜色只作为**补充的进度阶段提示**（见「补充设计：进度阶段色点」），不取代形态编码。

## 架构与数据流

- 新增 `RingStatusView: NSView`（约 80 行），只负责绘制
- `menuStyle == 2` 时 `statusItem.view = ringView`、`statusItem.length = 20`；其余两档仍走 `NSStatusBarButton` 文字路径，两套互斥
- `AppDelegate.tick()` 每 0.5s 把 `(phase, progress, isStealth)` 写入 view，**仅值变化时** `needsDisplay = true`（进度一分钟才动一点，避免空转）
- 绘制参数抽成纯函数 `ringSegments(phase:progress:)`，便于断言

## 交互

- 自绘 view 没有系统按钮行为：重写 `mouseDown` / `rightMouseDown`，转发到现有「左键开面板、右键开菜单」逻辑
- `toolTip` 保留完整信息（如「距离下班还有 2:32:30」）
- 点击高亮：自绘一层很淡的圆角底，替代系统蓝色高亮块
- 深浅模式：`viewDidChangeEffectiveAppearance()` 触发重绘

## 兜底与边界

- `NSStatusItem.view` 属较老 API；若某版 macOS 未渲染，回退到现有 SF Symbol 三态图标（旧路径保留不删）
- `progress` clamp 0–1；未知 phase 只画底环
- `currentIconName` 缓存保留给文字档的隐身图标（环模式不使用）；`ringUnavailable` 标志在 `statusItem.view` 未渲染时把有效档位降到 1，避免每帧反复重建

## 测试

- `--selftest`：进度环 3 项 + 色点 7 项（四档 + 边界 + 状态隐藏 + 几何不越界），共 33 项
- 构建后实测：三档启动、深浅模式切换、隐身/恢复、左键与右键、菜单栏项与悬浮窗尺寸

## 补充设计：进度阶段色点（2026-11-10 追加）

用户要求右下角加一颗按进度变色的点。

- **位置**：环右下角（约 4–5 点方向，`dist = r + 1.5`），直径 6pt（半径 3.0），故意压住环右下角一小段；不增加项宽。几何抽成 `ringDotGeometry(ringCenter:ringRadius:)`，自测验证在 20×22 视图内不越界且与环外缘重叠
- **颜色**：四段低饱和纯色，到边界直接切换（不渐变）
  - 0–25%：绿 `#5BAE84`
  - 25–50%：黄 `#DFC25E`
  - 50–75%：橙 `#E0A355`
  - 75–100%：红 `#D9706B`
- **显示范围**：仅 `.working` / `.before`；`.off` / `.rest` / 隐身不显示，避免下班后还挂着红点像警告
- **实现**：抽成纯函数 `ringDotColor(phase:progress:isStealth:) -> RingDot?`，返回 RGB 分量；`RingStatusView.draw` 末尾绘制
- **兼容性**：环本身仍单色、形态编码不变，色弱用户不受影响
- **测试**：6 项断言覆盖四档颜色、边界（0.249/0.25/0.499/0.5/0.749/0.75）、clamp 与状态隐藏，另有 1 项几何不越界

## 决策记录

- 选「进度环」而非「自绘精致图标」：同时解决宽度与信息量，而不只是换一个更好看的图标
- 选「形态编码为主、颜色为辅」：状态靠形态（色弱友好），颜色只表达工作中进度阶段
- 保留 SF Symbol 回退路径：自绘 view 是较老 API，降低兼容风险
- 保留点击高亮但改为淡圆角底：给操作反馈，同时避开显眼的系统蓝块

## 实现与验证结果

- 33 项自测全过（进度环 clamp / 三态形态 / 隐身降级 / 色点四档绿黄橙红、边界、状态隐藏、放大后几何不越界且压住环）
- CGWindow 按 PID 实测菜单栏窗口宽度：完整档 95、精简档 58、**进度环 36**（比精简窄 38%）
- 三档切换启动均正常；热键隐身后环仍在、悬浮窗消失，恢复后悬浮窗回来
- 模拟点击进度环 → 弹出 356×566 设置面板，Escape 可关闭（自绘 view 的点击与 popover 定位链路正常）
- 用户原有设置（紧凑模式等）在测试后完整恢复
- 编译仅有 `statusItem.view` 的 macOS 10.14 废弃警告，已由 `ringUnavailable` 回退路径覆盖
